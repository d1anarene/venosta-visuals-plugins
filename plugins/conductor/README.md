# Conductor (planned)

Turns music and other signals into keyframes on **any** effect parameter in Adobe Premiere Pro:
pick an audio clip, choose a frequency band (for example the kick drum), shape how the signal
becomes values or per-hit events, and write keyframes onto one parameter (for example Scale,
a Lumetri control, or one of our effects). Planned as a Premiere panel.

**Status: planned.** Nothing is built or tested yet. See [AGENTS.md](AGENTS.md) for the design
and [PROGRESS.md](PROGRESS.md) for the current state.
