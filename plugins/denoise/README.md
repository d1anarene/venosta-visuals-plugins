# Denoise (Premiere Pro + DaVinci Resolve) — planned

High-quality video noise reduction that keeps detail: a measured noise profile, motion-compensated
temporal filtering and a two-step spatial stage, with a fast **Preview** mode for editing and the
full **Final** mode for rendering.
